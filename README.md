# 数学・幾何アルゴリズムを学ぼう

幾何アルゴリズムの数学的な仕組みと、AutoCAD APIを使った実践を学ぶためのドキュメント。  
計算手順の暗記ではなく、数学的な仕組みの理解を重視する。

自分が普段使わないAPIや実装方法で書かれたコードでも、数学的な意味を読み解き、処理の意図を理解できるようになることを目指す。
