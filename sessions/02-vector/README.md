## 到達目標

- 内積の成分表示から角度・垂直・射影との関係を説明できる。
- 3D外積の向きと大きさを、基底・直交・面積に結び付けて説明できる。
- 2Dの左右判定と3Dの法線を区別し、順序の反転と退化を判断できる。
- ゼロベクトルと浮動小数点誤差を扱う際の前提を説明できる。

## 前提知識

[第1回の詳細解説](../01-matrix/explanation.md) のベクトルの成分・長さ・基底・右手系を使う。平方根、三平方の定理、sin・cos、余弦定理は本文で使い方を確認する。図の2D座標はX右・Y上、3Dは右手系とする。
