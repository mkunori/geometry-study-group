第1回と同じ青（#1565c0）・橙（#ba4b00）・紫（#7b3294）・灰（#58677c）と日本語フォントを使う。この回では青は第1の入力、橙は第2の入力、紫は求めた射影・外積・法線、灰は軸・補助線。色に加えて名前と座標・符号で区別する。

2DはX右・Y上。3Dは右手系を斜投影した模式図で、紙面の見かけの角度や長さを測らず、座標値と軸ラベルを読む。図05左だけは一般の鋭角を使った模式図で、共有数値例は右の直角の図に分けて示す。式と導出は画像だけにせず本文にも記載する。
