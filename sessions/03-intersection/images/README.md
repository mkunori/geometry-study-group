第1・2回と同じ青（#1565c0）・橙（#ba4b00）・紫（#7b3294）・灰（#58677c）と日本語フォントを使う。青と橙は比較する第1・第2の対象、紫はずれ・交点・共有区間・法線、灰は軸・補助線・対象外の延長部分を示す。色だけに頼らず、座標・名前・符号も併記する。

2DはX右・Y上。3Dは右手系の斜投影で、紙面の見かけの長さや角度を測らず座標と軸名を読む。面を描く四角形は無限平面の一部を示す模式図で、その輪郭を面の境界条件として使わない。主要な式と導出は図だけにせず本文に記載する。
