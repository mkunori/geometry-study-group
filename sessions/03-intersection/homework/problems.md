# 第3回：なぜ直線や平面の交点を計算できるのか？ — 宿題の問題

[詳細解説](../explanation.md) と同じ固定数値例を使い、交点を求める条件と結果の種類を確かめる。

## 宿題の目的

講義内容を復習し、計算結果だけでなく「なぜその計算で答えが得られるのか」を説明できるようにする。

## 前提と表記

- 同じ直交座標系の標準基底を使う。  
  2DはX右・Y上、3Dは右手系とする。  
- 点の差を変位ベクトルとし、点と変位を足して別の点を表す。  
  座標の単位は共通とする。  
- 媒介変数表示は $P+tr$ または $P+td$ 。  
  方向ベクトルは変位として扱い、t・uは無次元。  
  無限直線は任意の実数、半直線は0以上、閉線分は0以上1以下とする。  
- 2Dスカラー外積は $\mathrm{cross2}(a,b)=a_xb_y-a_yb_x$ 。  
  内積は $a\cdot b$ 、3Dベクトル外積は $a\times b$ と書く。  
- 通常の直線の方向と平面の法線は非ゼロである。  
  ゼロ方向は基本問題2の設問5で別に考える。  
  ゼロ法線では平面を定義できない。  
- ここでは整数・分数による厳密な計算を行う。  
  数値だけでなく、条件を満たす理由と必要な前提も述べよ。  
  浮動小数点での「ほぼゼロ」は詳細解説の⑧で扱う。

## 問題一覧

### 基本問題1：2D直線と媒介変数

$P=(0,0)$ 、 $r=(4,4)$ 、 $Q=(0,4)$ 、 $s=(4,-4)$ とする。

1. 2本の無限直線を $P+tr$ 、 $Q+us$ の成分で表せ。  
   第1の直線の $t=0,1$ と、第2の直線の $u=0,1$ は、それぞれどの点を表すか説明せよ。  
2. 交点の条件 $P+tr=Q+us$ から、2Dスカラー外積を使ってtとuの式を導け。  
   $w=Q-P$ と置き、sとの外積でuを消し、rとの外積でtを消せ。  
   割り算できる条件と、uの分子に負号が残るかどうかの理由も述べよ。  
3. 分母と2つの分子を成分から計算し、符号を確かめてt・uと交点を求めよ。  
   求めた点を両方の直線の式に代入して検算せよ。  
4. 同じ入力をPからP+r、QからQ+sまでの閉線分として見た場合にも交わるか答えよ。  
   t・uの範囲と端点を含むかどうかを使って説明せよ。

### 基本問題2：線分の交点・重なりと例外

各設問の入力は独立とし、直線と閉線分を区別する。

1. $P=(0,0)$ 、 $r=(2,0)$ 、 $Q=(3,-1)$ 、 $s=(0,2)$ とする。  
   無限直線のt・uと交点を求めよ。  
   同じ入力を2本の閉線分と見たとき、共有点があるかを範囲条件から説明せよ。  
2. 設問1のQだけを $(2,-1)$ に変えよ。  
   t・uと交点を求め、閉線分の内部での交差か端点での接触かを説明せよ。  
3. $P=(0,0)$ 、 $r=(4,0)$ 、 $s=(2,0)$ の2本の無限直線を考えよ。  
   Qが $(0,2)$ の場合と $(1,0)$ の場合で、共有部分はどう違うか答えよ。  
   方向どうしの外積と、位置のずれ $Q-P$ とrの外積を使って説明せよ。  
4. 同一直線上の閉線分 $(0,0)$ から $(4,0)$ と、 $(2,0)$ から $(6,0)$ の共有部分を求めよ。  
   第1線分のtに座標をそろえて範囲を比べ、結果を1つの交点として返してよいか述べよ。  
5. 方向がゼロの $P+t0$ や零長線分は、なぜ通常の直線とは別に扱う必要があるか答えよ。  
   両方が零長の場合と片方だけが零長の場合に、何を調べるべきか短く説明せよ。

### 基本問題3：3D直線と平面

三角形の頂点を $A=(0,0,2)$ 、 $B=(2,0,2)$ 、 $C=(0,3,2)$ とする。  
この3点を通る無限平面と、 $P=(1,2,0)$ 、 $d=(2,0,4)$ の無限直線を考える。

1. $n=(B-A)\times(C-A)$ を成分から求め、法線が非ゼロであることを確かめよ。  
   $n\cdot(X-A)=0$ から平面の条件を座標で表せ。  
2. 平面式に $X=P+td$ を代入し、tの式を導け。  
   分子・分母がそれぞれ何を表し、どの条件なら割り算できるか説明せよ。  
3. 分母と分子を求め、tと交点を計算せよ。  
   交点が元の平面条件を満たすことも確かめよ。  
4. 直線をPからP+dまでの閉線分に限定しても、平面と交わるか答えよ。  
   終点とtの範囲を使って説明せよ。  
5. 同じ平面に対し、方向を $d=(1,0,0)$ に変えた無限直線を考えよ。  
   Pが $(1,2,0)$ の場合と $(1,2,2)$ の場合で、共有部分はどう違うか答えよ。  
   分母だけでなく位置の条件も調べて説明せよ。

### (発展) 2平面の交線

無限平面 $\Pi_1:z=2$ と $\Pi_2:x=1$ を考える。

1. 各平面に対応する法線 $n_1,n_2$ を選び、その外積を求めよ。  
   外積が両平面に沿う方向になる理由を述べよ。  
2. 両平面の式を同時に満たす1点を求め、設問1の方向と組み合わせて交線の媒介変数表示を作れ。  
   全てのtで両平面の条件を満たすことを確認せよ。  
3. 法線の外積が交線の方向を与えても、それだけでは交線の位置が決まらない理由を説明せよ。  
4. $z=2$ と $z=5$ の組、 $z=2$ と $z=2$ の組について、共有部分を比較せよ。  
   非ゼロ法線が平行という情報だけで区別できるかも説明せよ。  
5. 補足として、無限平面の交線を求めても、有限な面パッチどうしの交わりをそのまま決められない理由を説明せよ。  
   追加で必要な条件は何か答えよ。
