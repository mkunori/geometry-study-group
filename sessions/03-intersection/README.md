# 第3回：なぜ直線や平面の交点を計算できるのか？

テーマはフィードバックによって変更する可能性がある。

## 到達目標

- 直線・半直線・線分を、同じ媒介変数表示と異なる範囲で説明できる。
- 2Dスカラー外積から2直線の交点式を導き、線分の範囲・端点・重なり・零長を区別できる。
- 法線による平面式から直線との交点を導き、2平面の交わりが直線になる理由を説明できる。
- 一点・共有点なし・無数の共有点と、退化・数値的に不安定な場合を区別できる。

## 前提知識

[第1回](../01-matrix/explanation.md) の座標・ベクトル・行列と、[第2回](../02-vector/explanation.md) の内積・外積・法線・射影を使う。2DはX右・Y上、3Dは右手系を引き継ぐ。一次方程式の解き方を知っていると読み進めやすい。
