第1〜3回と同じ日本語フォントと、青（#1565c0）・橙（#ba4b00）・紫（#7b3294）・灰（#58677c）を用いる。色だけで判別せず、基底名・頂点番号・座標・矢印を併記する。

3Dは右手系の斜投影。紙面の見かけの長さや角度ではなく、軸名と座標を読む。図02はCを基準にした変位の図で、世界原点からの距離を縮尺表示していない。図06は両端とも+X側から見て比較する。図08はXY平面を上から見ており、B=+Zは紙面の手前向き。図09の干渉は概念図で、固定例Cの完成スイープ形状を示すものではない。
