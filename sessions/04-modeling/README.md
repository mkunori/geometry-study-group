# 第4回：なぜ2Dの図形から3Dモデルを作れるのか？

テーマはフィードバックによって変更する可能性がある。

## 到達目標

- 2D断面の点を、原点と2つの基底で3Dへ配置し、4×4列方式の変換と対応付けられる。
- 直線押し出しの頂点・側面・端面を作る理由と、頂点順序から外向き法線が決まる仕組みを説明できる。
- 閉じた長方形直柱メッシュの接続と、断面積×長さによる体積の検算を理解する。
- 経路に沿う配置では、位置だけでなく局所フレームの向きとコーナー処理が必要な理由を説明できる。
- 退化・ねじれ・自己交差・閉じ忘れに注意し、連続立体・三角形メッシュ・CADソリッドを区別できる。

## 前提知識

[第1回](../01-matrix/explanation.md) のローカル座標・4×4変換、[第2回](../02-vector/explanation.md) の内積・外積・法線、[第3回](../03-intersection/explanation.md) の直線・平面・交差を使う。右手系と列ベクトル方式を引き継ぎ、角度・長さ・座標の単位をそろえる。
