# 第4回：なぜ2Dの図形から3Dモデルを作れるのか？ — 復習用の宿題

基本3問＋発展1問。問題と解答・解説は別ページで確認する。

## 宿題の目的

局所座標を世界座標へ配置する仕組み、断面から面と体積を作る条件、頂点順序と外向き法線、経路上のフレームの役割を、手計算と自分の言葉で説明できるようにする。
