# 図形変換の練習問題

コード読解・変換結果の予想・数学的な意味の説明を組み合わせ、見慣れないAPIでも処理の意図を読み解く練習を行う。  
計算結果だけでなく、入力の座標系や変換の向き、なぜその結果になるかを説明することを重視する。

## 問題と解答

| 教材 | 内容 |
| --- | --- |
| [練習問題](problems.md) | 基本3問でWCS・OCS・任意軸・相互変換を、発展1問で合成順序と移動の基準を読み解く |
| [解答・解説](solutions.md) | 小問ごとの期待値・途中計算・コードの意図・成立条件・誤った実装との差を確かめる |

必要なAPIの用途・引数・戻り値は問題中に示す。  
AutoCADなしでも読解・手計算で解ける構成とし、実機実行は任意の確認とする。  
職場の参照DLLによるビルド・NETLOAD・AutoCAD実機での結果照合は未検証であり、数値は数学上の期待値として扱う。

## 演習の組み立て方

- 複数のコードを読み、同じ処理を表しているか、どこで条件や順序が違うかを説明する。
- 固定入力から変換前後の座標を予想し、基底・行列・途中計算で確かめる。
- WCS・OCS・任意軸アルゴリズムを中心に、適用条件や境界・退化・丸め誤差も考える。

問題は基本3問＋発展1問とし、対応する講義の内容と整合させる。  
設問は「求めよ」「説明せよ」の形式とし、発展要素は項目名に「(発展)」を付ける。  
問題の原本は `problems.md`、解答・解説の原本は `solutions.md` に分ける。  
解答には計算過程と考え方を記載し、図解は [共通のimagesディレクトリ](../images/README.md) を利用する。
