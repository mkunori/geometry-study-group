# AutoCAD実践編：同じ図形変換のいろいろな実現方法を見てみよう

普段と違うAPIで書かれた変換も、座標・基底・行列へ立ち返って読んでみよう。
WCS・OCS・任意軸アルゴリズムを最優先に、複数の変換方法を数学で結び付ける。

## 到達目標

- 自分が普段使わないAPIや実装方法でも、数学的な意味を読み解き、処理の意図を理解する。
- 座標の値だけでなく、どの座標系の点・方向を表しているかに注目する。
- 同じ固定入力に対する座標・基底・行列・途中計算を照合し、変換方法の共通点と適用条件を説明する。

## 対象読者

AutoCADの.NET APIなどで図形を操作した経験があり、C#と行列の基本操作を知る開発者を対象とする。
基底・内積・外積・行列変換は、実務の題材と結び付けて振り返る。

## 教材の概要

「同じ頂点なのに、なぜ異なる座標が返る？」という疑問から始める。
WCS・UCS・OCSの役割、法線からOCS基底を作る任意軸アルゴリズム、OCSとWCSの相互変換を中心に置く。
移動・回転・逆変換・合成も、座標系と処理の意図を読み解く題材として扱う。

各題材は「API紹介 → 図解 → 詳細説明」の順で読む。  
何をするAPIかを確認し、図でイメージをつかんでから、固定入力・複数のコード・数学的な理由・期待結果・使い分けを照合する。  
見た目が同じという理由だけで、変換が等価だと結論しない。

数学基礎編とは別の教材として管理し、実際の開催順は固定しない。
数学の復習には [第1回の座標変換](../01-matrix/explanation.md) と [第2回の内積・外積](../02-vector/explanation.md) を参照できる。
