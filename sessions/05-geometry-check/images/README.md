第1〜4回と同じ日本語フォントと、青（#1565c0）・橙（#ba4b00）・紫（#7b3294）・灰（#58677c）を使う。色だけに頼らず、点名・座標・法線・分類・区間を添える。本文の画像には内容を表す代替テキストを付け、主要な式を画像だけにしない。

2DはX右・Y上。図07の横軸qはXYのX軸ではなく、斜め軸への内積の値を並べたもの。3Dは右手系の斜投影で、紙面の角度や見かけの長さではなく座標と軸名を読む。半空間やAABBの方法の適用範囲は本文と合わせ、模式的な描画だけで有効ソリッドと判定しない。
