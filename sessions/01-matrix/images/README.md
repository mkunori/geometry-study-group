# SVG図解の保管先

第1回の [詳細解説](../explanation.md) で使う静的SVG図解。宿題の解答でも共通の図を利用する。

| 図 | 内容 |
| --- | --- |
| [01：図形の変換](01-transform-overview.svg) | 三角形の各頂点に同じ変換を適用 |
| [02：行列の列と基底](02-matrix-columns.svg) | 掛け算と基底の線形結合 |
| [03：単位円](03-unit-circle.svg) | cos・sinと座標の関係 |
| [04：基底の回転](04-rotated-basis.svg) | 回転した基底を列に並べる |
| [05：点の90°回転](05-point-rotation.svg) | 点 $(2,1)$ から $(-1,2)$ へ |
| [06：原点と平行移動](06-origin-and-translation.svg) | 線形変換だけでは移動を表せない理由 |
| [07：2Dの同次座標](07-homogeneous-2d.svg) | 2×2から3×3への拡張 |
| [08：点と方向](08-points-and-directions.svg) | $w=1$ と $w=0$ の違い |
| [09：同次変換の構造](09-homogeneous-structure.svg) | 3×3と4×4の領域比較 |
| [10：ローカルとワールド](10-local-world.svg) | 3D座標系と点の配置 |
| [11：合成順序](11-composition-order.svg) | 回転→移動と移動→回転の比較 |

2DはX軸が右、Y軸が上。正の回転は反時計回り。青は変換前、橙は変換後、紫は移動量を表す。3D図は右手系の斜投影で、軸の名前と座標値を併記する。構造図は橙が線形変換、紫が移動列、灰が同次成分の保持を表す。
